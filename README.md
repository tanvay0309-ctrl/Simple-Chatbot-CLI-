# 🤖 Simple Chatbot (CLI)

The **Simple Chatbot (CLI)** is a beginner-friendly chatbot application developed using **Python**. It is designed to interact with users through the command-line interface and respond to basic questions, greetings, and predefined commands.

The chatbot uses **conditional statements, functions, string handling, and user input** to understand simple messages and provide appropriate responses. Users can start a conversation by entering messages such as greetings, asking for basic information, or using supported commands. The chatbot processes the input and generates a suitable predefined response.

The program continues the conversation until the user enters an exit command, allowing for a simple and interactive chat experience directly from the terminal.

## ✨ Features

- 🤖 Interactive chatbot conversation
- 👋 Responds to common greetings
- 💬 Handles predefined questions and commands
- 🔤 Basic text and string processing
- 🚪 Exit command to end the conversation
- 🖥️ Simple command-line interface
- 🐍 Built entirely using Python

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Interface:** Command Line / Terminal

## 🎯 Objective

The main objective of this project is to understand how user input can be processed to create interactive applications. It helps strengthen Python fundamentals such as **loops, functions, conditional logic, string manipulation, and input handling** while providing practical experience in developing a simple conversational program.
